# Code for the genomic analyses in the manuscript

| Directory | Analysis |
|---|---|
| `01_public_metagenome/` | Screening of public faecal metagenomes for *Kazachstania pintolopesii*, and scoring of the positive runs against the two isolates of this study |
| `02_sv_scan/` | Genome-wide scan for copy-number and presence/absence differences between the guinea-pig-derived and mouse-derived isolates, run in both directions |
| `03_promoter_stre_yap1/` | Promoter extraction, STRE motif scoring and Yap1 binding-site scanning |
| `04_figures/` | The code that draws the genomic figure panels |
